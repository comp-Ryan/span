# Owed frontend brief (Paper)

Built in Paper by Ryan with Claude driving via the Paper MCP. Consumes `docs/api-contract.md`. Design against `docs/frontend/fixture-run-palletbay.json` (234 real events from Palletbay, generated by `backend/scripts/make_fixture.py`).

## The one screen
Desktop 1440×900, dark `#0F0E13`. Left 60%: the **workflow canvas**, nodes appear top-to-bottom as events arrive, thin connectors. Right 40%: **transcript** (the call) on top, **report** button at the bottom. Top bar 56px: "Owed" (serif) · company name (muted) · green dot "on call · 0:42".

Type: serif only for the answer node and the brand (Instrument Serif / Newsreader). Sans everywhere else (Inter / Geist) 14 / 12. Text `#EBE8F0`, muted `#9A95A8`, panel `#17161D`, border `#2A2833`. One accent `#FF7A45` (answer border, action buttons). Bands on scoring rows only: green `#5FCF8A`, amber `#F5C451`, red `#F06A6A`. Motion: nodes fade in and slide to position; counters tick; nothing else.

## Six node types (from contract `node.create` / `node.update`)
| type | shows | states |
|---|---|---|
| context | company, next payroll date, payroll due by target, bills due by target, bank balance | running → done |
| scoring | progress `done/total`, rows ticking in (customer, amount, days late, band dot, % paid by target) | running (progress bar) → done (fade at bottom) |
| forecast | owed total, expected by target, payroll+bills need, cash at target, **gap**; re-fires on payments | running → done, then updates |
| answer | one serif line, spoken text below, accent border | done |
| levers | 2–3 branches with recovers $, targets list with one reason each, the spoken ask; the `decision` attaches here as buttons | running → done → waiting |
| action | kinds: reminder (draft body, tone, sent), reply (text + classification), negotiation (rounds, then decision with 8s auto-resolve), payment (amount, rail, receipt), portal, check_photo | running → done |
